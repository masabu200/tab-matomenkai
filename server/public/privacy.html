タブまとめん改 プライバシーポリシー

制定日: 2026年10月28日（最終更新日: 2026年10月29日）

KWS（以下「当方」）は、Chrome 拡張機能「タブまとめん改」（以下「本拡張」）と、その有料版（以下「Pro 版」）の提供にあたり、個人情報の保護に関する法律その他の法令を守り、利用者の情報を次のとおり取り扱います。

2. お使いのブラウザの中だけに保存する情報

本拡張は、次の情報をお使いの Chrome の中（chrome.storage.local）にだけ保存します。当方を含む第三者のサーバーへは送りません。

  • 保存したスペース・カテゴリー・タブ（タイトル、URL、ファビコンの URL、タブグループの名前と色、並び順）
  • 設定（表示の仕方、言語、テーマ、自動バックアップの間隔、切り替え時の自動保存など）
  • 最小限の利用の記録（レビューのお願いを出す時期を決めるための「使った日」の一覧と表示回数・表示しない設定、自動整理のための各スペースの最終利用日時）
  • 自動整理で削除したスペース（ゴミ箱。30日後に自動で消去）

アクセス解析や広告のための計測は行っていません。

3. 外部へ送る情報

本拡張が外部へ情報を送るのは、次の場合に限ります。

Google ドライブへのバックアップ

  • 「Google ドライブに接続」を押して許可すると、「今すぐバックアップ」を押したとき、また Pro 版の自動バックアップを有効にした場合は設定した間隔ごとに、保存データ（スペース・カテゴリー・タブ）を JSON ファイルとしてあなた自身の Google ドライブに書き込みます。
  • 求める権限は drive.file（本拡張が作ったファイルだけを扱える権限）です。ほかのファイルは読みません。
  • 認証は Chrome と Google が管理し、当方がその情報を受け取ることはありません。接続はいつでも設定から解除できます。

Pro 版の購入と購入状況の確認

  • Pro 版の購入状況を確かめるため、本拡張はインストールごとに作るランダムな文字列（以下「購入 ID」。64桁の英数字）を、当方の購入記録サーバー（Cloudflare, Inc. の Cloudflare Workers 上で動作）に送ります。名前、メールアドレス、閲覧履歴、保存したタブは送りません。
  • 購入 ID は Chrome の同期ストレージ（chrome.storage.sync）に保存され、同じ Google アカウントで同期している Chrome の間で共有されます。
  • 購入の手続きと支払いは Stripe, Inc. と、その関連会社で販売者となる Link, LLC（以下「決済事業者」）の画面で行います。メールアドレス、カード番号などの支払い情報は決済事業者が直接受け取り、各社のプライバシーポリシーに従って扱います。当方はカード番号を受け取りません。
  • 購入記録サーバーには、購入 ID と結び付けて、決済事業者の顧客 ID・契約 ID・契約の状態（有効、解約予約、解約済みなど）と期間の終了日を保存します。当方は、決済事業者の管理画面で、購入者の名前・メールアドレス・国と、取引の記録を確認できます。

ローカル AI 連携（任意・上級者向け）

  • 接続キーを入力して接続した場合だけ、あなたの PC の中で動く連携サーバー（127.0.0.1）に、スペースのタイトル・URL・グループの情報を送ります。ページの本文は送りません。インターネット上のサーバーには送りません。

レビューのお願い・お問い合わせ

  • 「レビューを書く」は Chrome ウェブストアのページを開くだけで、情報は送りません。「ご意見を送る」はメールソフトを開くだけで、送信するかどうかはあなたが決めます。

4. 利用目的

当方が受け取る情報（購入記録サーバーの情報、決済事業者から受け取る情報、お問い合わせの内容）は、次の目的でだけ使います。

  • Pro 版の提供、購入状況の確認、解約・返金などの手続き
  • お問い合わせへの回答とサポート
  • 法令に基づく帳簿の作成・保存、不正な利用への対応

5. 第三者への提供

法令に基づく場合を除き、あらかじめ同意を得ずに第三者へ個人情報を提供しません。上に書いた決済事業者（Stripe, Inc.・Link, LLC）とサーバーの提供元（Cloudflare, Inc.）には、各サービスの提供に必要な範囲でだけ情報を預けます。これらの事業者は日本の外（主に米国）にある場合があり、各社の定める方針と米国等の法令に従って情報を扱います。

6. 安全管理

購入記録サーバーへの通信は暗号化（HTTPS）しています。決済事業者からの通知は署名を確かめてから受け付け、管理に使う鍵は当方だけが扱える場所に保管します。

7. 保存期間と削除

  • 本拡張をアンインストールすると、ブラウザの中に保存したデータはすべて消えます。
  • Google ドライブ上のバックアップは、あなたのドライブで削除してください。Google アカウントへのアクセス許可は、Google アカウントの「セキュリティ」→「サードパーティ製のアプリとサービス」からいつでも取り消せます。
  • 購入記録サーバーの情報と決済の記録は、契約の終了後も、法令で求められる期間（帳簿の保存期間など）は保存します。それ以外の削除を希望する場合は、購入 ID（設定の「Pro 版」→「購入 ID」に表示）を添えて下記へご連絡ください。

8. 開示・訂正・利用停止のご請求

ご本人から、保有する個人情報の開示・訂正・利用停止などのご請求があった場合は、ご本人であることを確かめたうえで、法令に従って対応します。下記の窓口へご連絡ください。

9. 変更

内容を変更する場合は、本ページと Chrome ウェブストアの掲載情報を更新し、更新日を書き換えます。重要な変更は、拡張機能の画面でもお知らせします。
