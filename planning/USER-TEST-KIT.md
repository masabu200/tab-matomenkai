## 2. アンケート（初回・3日後）

所要 3〜5分。Google フォームなどにそのまま写せる形式。

1. ふだん、Chrome で同時に開いているタブはだいたい何枚ですか？
   - 〜10枚 / 11〜30枚 / 31〜50枚 / 51枚以上
2. 並行して進めている案件・作業はいくつくらいですか？
   - 1つ / 2〜3つ / 4〜6つ / 7つ以上
3. インストールしてから、スペースを作ってタブを保存できましたか？
   - できた / 途中でつまずいた / まだ試していない
4. （つまずいた方）どこで迷いましたか？（自由記述）
5. スペースを切り替えて、タブが入れ替わるところまで使いましたか？
   - 使った / まだ / 使ったが期待と違った
6. 最初の印象で、いちばん便利そうだと思った機能はどれですか？（1つ）
   - スペースの切り替え / ピン留めタブ / 一括操作 / 右クリック保存 / Googleドライブのバックアップ / スペースの共有 / その他
7. 分かりにくかったところ・不安に感じたところがあれば教えてください。（自由記述）

## 3. アンケート（2週間後）

所要 5分。最後の価格の質問は「払う気持ち」と「実際に払うか」を分けて聞く。

1. この2週間で、タブまとめん改を使った日はどれくらいですか？
   - ほぼ毎日 / 週3〜4日 / 週1〜2日 / ほとんど使わなかった
2. 使わなかった日があった方：使わなかった理由は？（複数可）
   - 忘れていた / 自分の作業に合わなかった / 操作が面倒 / 不具合があった / その他（自由記述）
3. 使う前と比べて、タブを探す・開き直す手間はどう変わりましたか？
   - かなり減った / 少し減った / 変わらない / 増えた
4. よく使った機能を選んでください。（複数可）
   - スペースの切り替え / カテゴリー / ピン留めタブ / 一括操作 / 元に戻す / 右クリック保存 / URL一覧のコピー / Googleドライブのバックアップ / 使っていないスペースの自動整理 / スペースの共有
5. タブまとめん改が明日から使えなくなったら、どう感じますか？
   - とても困る / 少し困る / 特に困らない
6. 作業データを失う不安について、当てはまるものは？
   - PCの故障やブラウザの不具合でタブを失ったことがある / 失ったことはないが不安 / 特に不安はない
7. 次の有料機能があるとしたら、ほしいですか？（それぞれ「ほしい／どちらでも／いらない」）
   - Googleドライブへの自動バックアップ（変更があったら自動で保存、Chromeを再起動しても継続）
   - 複数のPC間でスペースを同期
   - バックアップ履歴から、スペース1つだけを戻す
8. 上のうち「ほしい」を選んだ機能のセットに、月額いくらなら払ってもよいと思いますか？
   - 払わない / 〜200円 / 300円前後 / 500円前後 / 800円前後 / 1,000円以上
9. 年払いならいくらまで払えますか？（自由記述・任意）
10. 正式に有料版が出たとき、実際に申し込むと思いますか？
    - すぐ申し込む / 試用期間があれば検討する / たぶん申し込まない
11. 改善してほしいこと・追加してほしい機能があれば教えてください。（自由記述）
12. 有料版が出たときに案内を受け取ってもよい方は、連絡先を書いてください。（任意）

## 4. 集計と判断（計画書 8節に記録する）

| 指標 | 計算 | 次に進む目安 |
|---|---|---|
| 初回利用成功 | 初回アンケートの Q3「できた」÷ 回答者数 | 8割以上。下回ったら初回案内（BASE-03）を見直す |
| 2週間後の継続 | 2週間後 Q1「週3日以上」の人数 | 3人以上 |
| 困る度 | Q5「とても困る」の人数 | 3人以上 |
| 支払意思 | Q8 で 300円以上を選んだ人数 | 3人以上 |
| 購入意思 | Q10「すぐ申し込む」＋「試用があれば検討」 | 3人以上（実購入は別に記録） |
| 欲しい有料機能 | Q7 の「ほしい」の数 | 自動バックアップが最多なら現行の方針どおり |

- 目安を満たせば、決済（PAY-02〜05）の実装に進む。
- 満たさなければ機能追加を止め、対象者・訴求・使いにくさを見直す（計画書 4節）。
- 「払ってもいい」と「実際に買う」は別に記録する。ストアのユーザー数は継続率の代わりにしない。
