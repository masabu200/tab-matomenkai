# タブまとめん改 — Chrome Web Store 公開手順ガイド

このガイドに沿って進めると、`store-assets/タブまとめん改_v1.2.0.zip` をストアに公開できます。
所要時間は準備済みのため約 15〜30 分、審査には通常 1〜数日（稀に 1〜2週間）かかります。

---

## Step 0. 事前準備（必要に応じて）

- **デベロッパーアカウント**: Chrome Web Store のデベロッパー登録は **一回だけ $5（約750円）** かかります。未登録なら下記 Step 1 で登録します。
- 登録には Google アカウントとクレジットカード（または Google Play 残高）が必要です。
- すでにデベロッパー登録済みであれば Step 2 から始められます。

---

## Step 1. デベロッパーアカウントの登録（初回のみ）

1. [Chrome Web Store デベロッパー登録](https://chrome.google.com/webstore/devconsole/register) を開く
2. 使用する Google アカウントでログイン
3. デベロッパー登録料 $5 を支払う
4. デベロッパー名（ストアに表示される名前）を設定

> デベロッパー名は後から変更できます。個人で公開する場合は「mugikura」等でOKです。

---

## Step 2. 新しいアイテムを作成

1. [デベロッパーコンソール](https://chrome.google.com/webstore/devconsole) を開く
2. **「新しいアイテム」** をクリック
3. **「パッケージを追加」** で `store-assets/タブまとめん改_v1.2.0.zip` をアップロード
   - ZIPの先頭にフォルダが入らないよう作ってあります（ファイルがルートに配置）
4. アップロード後、拡張機能の詳細編集画面が開きます

---

## Step 3. ストア掲載情報を入力

`store-assets/ストア掲載文.md` をコピーして入力してください。

| 欄 | 入力内容 |
|----|---------|
| 説明 | 掲載文の「説明文（Description）」を貼り付け |
| カテゴリ | 生産性向上（Productivity） |
| 言語 | 日本語 |
| アイコン | `store-assets/icons/icon128.png`（128x128） |
| スクリーンショット | `store-assets/screenshot-1-list-light.png`（1280x800）を1枚目に。<br>`screenshot-2-card-dark.png` も2枚目に追加可（最大5枚） |
| プロモーション画像（任意） | `promo-small-440x280.png` / `promo-marquee-1400x560.png` |
| 発行者 | お使いのデベロッパー名 |
| ウェブサイト（任意） | GitHub Pages などがあれば。なくてもOK |

> スクリーンショットは **1280x800 または 640x400** のみ受け付けられます。用意したものは 1280x800 です。

---

## Step 4. プライバシー（データの安全性）を申告

「プライバシー」タブで、**「データの安全性」フォーム** を開き、`ストア掲載文.md` の「データ利用に関する開示」の回答例に従って入力します。

ポイント：
- **タブのURL・タイトル**を収集する旨を申告する（外部送信はしない）
- 送信がないため **プライバシーポリシーURLは必須ではありません**
- 万一必要になった場合は `プライバシーポリシー.md` を GitHub Pages 等で公開してURLを貼ってください

---

## Step 5. その他の必須項目

- **単一の目的**: 「タブ整理・切り替え」という明確な単一目的になっていることを確認（問題なし）
- **権限の説明**: 説明文に権限の理由を記載済み

---

## Step 6. 審査に提出

1. 右上の **「審査用に送信」** をクリック
2. 確認ダイアログ → **「提出」**

審査中は「審査中」ステータスになります。結果はメールで通知されます。

- **公開（承認）** → 通常 1〜2営業日でストアに公開（公開範囲設定が「公開」の場合）
- **却下・修正要求** → メールに理由が記載されるので、修正後に再提出

---

## Step 7. 公開後の更新（バージョンアップ）

更新するときは：

1. `manifest.json` の `version` を上げる（例：`1.2.0` → `1.2.1`）
2. ZIPを作り直す（`store-assets/` で同じ手順）
3. コンソールの該当アイテム → **「新しいパッケージをアップロード」** → ZIPを選択
4. 変更内容を記入して **「審査用に送信」**

---

## トラブルシューティング

| 症状 | 対処 |
|------|------|
| アイコンがアップロードできない | 128x128 以上・正方形・PNG であることを確認（用意済みの `icons/icon128.png` を使用） |
| パッケージが無効と言われる | ZIP の中身を確認（`.git` や `store-assets` が入っていないか）。このガイドの手順で作った ZIP は問題ありません |
| スクリーンショットのサイズエラー | 1280x800 または 640x400 の PNG のみ使用 |
| 「単一目的」違反で却下 | タブ整理に無関係な機能（広告表示など）を追加しないこと |
