## 説明文（Description）

以下をそのまま Description 欄に貼り付けてください。

```
案件・プロジェクトごとにタブをまとめて、ワンクリックで切り替えられるChrome拡張機能です。

■ こんな方におすすめ
・複数の案件やプロジェクトを同時進行していて、タブが散らかる
・案件ごとにタブを開き直すのが面倒
・タブの整理を手軽に自動化したい

■ できること
・スペース（案件ごとのタブの入れ物）を作成・保存・ワンクリック切り替え
・タブグループをそのまま保存し、復元時も再現
・カテゴリーでスペースを3階層まで整理
・タブのタイトル・URLでのリアルタイム検索
・リスト / カード表示の切り替え
・ダークモード対応
・スペースごとのテーマカラー・アイコン設定
・自動バックアップ（毎時 / 6時間ごと / 毎日）とJSONでのエクスポート・インポート

■ 使い方
1. ツールバーのアイコンをクリックしてダッシュボードを開く
2. 「＋ スペース」で案件名を入力
3. 保存したいタブを開いた状態で「現在のタブを保存」をクリック
4. サイドバーのスペース名をクリックすると、その案件のタブが一斉に開きます

■ データについて
保存したタブ情報はすべてお使いのChromeブラウザ内（chrome.storage.local）にのみ保存されます。
外部サーバーへの送信・収集は一切行いません。

■ 権限について
・tabs：現在開いているタブのタイトル・URLを保存するために使用します
・storage：保存したデータを端末内に保持するために使用します
・tabGroups：Chromeのタブグループ構造を保存・復元するために使用します
・alarms / downloads：自動バックアップ機能に使用します
・全サイトでのコンテンツスクリプト：マウスの「進む」ボタンでダッシュボードに移動できる機能のためです
```

## データ利用に関する開示（プライバシー欄の回答例）

Chrome Web Store の「データの安全性（Data safety）」フォームの回答例です。

| 質問 | 回答 |
|------|------|
| ユーザーデータを収集しますか？ | はい（限定された項目のみ） |
| 収集するデータの種類 | ・閲覧履歴／アクティビティ（開いているタブのタイトル・URL） |
| データは暗号化して送信されますか？ | 送信自体をしていません（すべてローカル保存） |
| データは暗号化して保存されますか？ | はい（Chrome標準のローカルストレージに保存） |
| 個人情報の販売 | いいえ |
| データの使用目的 | コア機能（スペースへのタブ保存・復元）のため |
| サードパーティとの共有 | なし |
| 認証情報（パスワード等）の収集 | なし |
| プライバシーポリシーURL | 任意（ローカル保存のみのため必須ではありません） |

> 補足：タブのタイトル・URLは「閲覧履歴／アクティビティ」に分類されます。しかし外部送信は行わないため、プライバシーポリシーURLの提出は必須ではありません。安心のため公開ページを用意してもよいでしょう。

## 審査で注意されそうなポイント

1. **`<all_urls>` のコンテンツスクリプト**
   - 権限警告「すべてのサイトでデータを読み取って変更する」が表示されます
   - 理由はマウス「進む」ボタンでダッシュボードへ移動する機能のためです
   - 説明文に理由を明記してあるので、審査通過は想定されますが、確認が入る可能性があります
2. **tabs 権限**
   - 「閲覧履歴の読み取り」警告が出ます
   - タブ保存というコア機能のため、同カテゴリの拡張機能では一般的です
3. **データ収集の開示**
   - タブURLを保存するため、プライバシー欄の申告漏れがないよう上記の回答例を使ってください
