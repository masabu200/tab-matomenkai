# タブまとめん改 利用規約

制定日: 2026年10月29日

この規約は、KWS（以下「当方」）が提供する Chrome 拡張機能「タブまとめん改」（以下「本拡張」）と、その有料版（以下「Pro 版」）の利用条件を定めるものです。本拡張を利用した時点、または Pro 版を購入した時点で、この規約に同意したものとみなします。

## 第1条（提供内容）
1. 本拡張は、開いているタブをスペースごとに保存・復元するための道具です。基本の機能は無料で利用できます。
2. Pro 版を購入すると、Google ドライブへの自動バックアップ（以下「Pro 機能」）が使えるようになります。Pro 機能の内容は、本拡張の画面と特定商取引法に基づく表記に示すとおりです。
3. 当方は、利用者への事前の通知により、機能を追加・変更することがあります。Pro 機能を廃止する場合は、相当の期間をおいて事前にお知らせし、その時点で契約期間が残っている利用者には、残りの期間に応じた料金を返金します。

## 第2条（Pro 版の購入と料金）
1. Pro 版は月額の継続契約です。料金、支払方法、支払時期は、特定商取引法に基づく表記と決済画面に示すとおりです。
2. 支払いは、Stripe, Inc. の決済サービス（販売者として Link, LLC が表示されます）を通じて行います。決済に関する手続きには、各社の規約も適用されます。
3. 契約は、本拡張が作る購入 ID と結び付けて管理します。別のパソコンで使う場合や、本拡張を入れ直した場合は、設定の「購入 ID」から引き継いでください。購入 ID は第三者に知らせないでください。

## 第3条（更新と解約）
1. 契約は、解約の手続きがない限り、1か月ごとに同じ条件で自動で更新されます。
2. 利用者は、設定の「Pro 版」→「契約の確認・解約」から、いつでも解約できます。解約後も、支払い済みの期間の終わりまでは Pro 機能を利用できます。
3. 支払い済みの料金は、原則として返金しません。ただし、当方に責任がある不具合により Pro 機能を利用できなかった場合は、個別にご相談に応じます。
4. 支払いが確認できない場合（カードの有効期限切れなど）、決済事業者が再度の請求を試みる期間を経て、Pro 機能が使えなくなることがあります。無料の機能と、保存したデータには影響しません。

## 第4条（データの管理）
1. 保存したタブなどのデータは、利用者のブラウザと、利用者自身の Google ドライブに保存されます。当方はその内容を受け取りません。
2. 大切なデータは、利用者の責任で、バックアップを取るなどして管理してください。当方は、データの消失を防ぐよう努めますが、すべての状況でデータの保全を保証するものではありません。
3. 情報の取り扱いは、別に定めるプライバシーポリシーによります。

## 第5条（禁止事項）
利用者は、次の行為をしてはなりません。
1. 法令や公序良俗に反する行為
2. 本拡張や購入記録サーバーに過度な負荷をかける行為、不正に Pro 機能を利用する行為、他人の購入 ID を使う行為
3. 本拡張を改変・複製して、再配布または販売する行為

## 第6条（免責）
1. 当方は、本拡張が利用者の特定の目的に合うこと、不具合がないことを保証しません。不具合を知った場合は、できるだけ早く修正するよう努めます。
2. Google ドライブ、Chrome、決済事業者など、当方以外のサービスの停止・変更により生じた不利益について、当方は責任を負いません。
3. 当方の責任が認められる場合でも、当方に故意または重大な過失がある場合を除き、当方が負う責任の上限は、その利用者が直近の1か月に当方へ支払った Pro 版の料金の額とします。消費者契約法その他の法令により、この上限が適用されない場合はこの限りではありません。

## 第7条（規約の変更）
当方は、法令の変更やサービスの内容の変更に合わせて、この規約を変更することがあります。変更する場合は、変更の内容と効力が生じる日を、本ページと本拡張の画面で事前にお知らせします。料金を上げる場合は、効力が生じる日の30日前までにお知らせし、利用者はそれまでに解約できます。
