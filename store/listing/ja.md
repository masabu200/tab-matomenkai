# Chrome ウェブストア掲載文（日本語）

## 名前（45文字以内）
タブまとめん改

## 概要（132文字以内）
案件ごとに「スペース」を作り、同じウィンドウでタブ構成をまるごと切り替え。保存・復元・一括操作・元に戻す・右クリック保存。多言語対応。

## 詳細説明
タブまとめん改は、仕事やプロジェクトごとにタブを「スペース」として保存し、同じ Chrome ウィンドウの中でタブ構成をまるごと切り替えられる拡張機能です。

■ できること
- スペース：案件ごとにタブ一式を保存。クリック一つで切り替え。切り替え時に今のタブを自動保存することもできます。
- カテゴリー：スペースを階層で整理。ドラッグで移動、色やアイコンで見分けられます。
- タブグループ：Chrome のタブグループをそのまま保存・復元。
- 一括操作：タブを選んで開く・移動・グループへ入れる・アーカイブ・削除。全選択と Shift 範囲選択に対応。
- 元に戻す：削除やアーカイブを直後に取り消し（Ctrl/⌘+Z）。
- URL 一覧のコピー：Markdown、タイトル+URL、URL のみの形式でクリップボードへ。
- 右クリック保存：閲覧中のページやリンクを、右クリックから任意のスペースに保存。
- 左サイドパネル：Chrome のサイドパネル（左配置）に左バーを出し、ページ閲覧中も見えたままに。
- キーボード：Ctrl/⌘+S 保存、Ctrl/⌘+K スペース検索、/ 絞り込み。
- バックアップ：JSON のエクスポート/インポート、定期自動バックアップ、Google ドライブへの手動バックアップ。
- 10言語：日本語・英語・簡体字中国語・繁体字中国語・韓国語・スペイン語・ポルトガル語（ブラジル）・ドイツ語・フランス語・イタリア語。設定から切り替えられます。

■ データの扱い
保存データはお使いの Chrome のローカルストレージにのみ保存されます。Google ドライブへのバックアップは、あなたが「接続」と「今すぐバックアップ」を押したときだけ、あなたの Google アカウントのドライブに書き込みます。閲覧内容を外部へ送信する機能はありません。

## 権限の説明（ダッシュボード用）
- tabs / tabGroups：開いているタブとタブグループを読み取り、スペースとして保存・復元するため。
- storage / unlimitedStorage：スペースと設定をローカルに保存するため。
- alarms：定期自動バックアップのため。
- downloads：JSON バックアップをダウンロードフォルダに書き出すため。
- sidePanel：左バーを Chrome のサイドパネルに表示するため。
- contextMenus：右クリックメニュー「タブまとめん改に保存」のため。
- identity：Google ドライブへのバックアップ保存の認可を得るため（drive.file スコープのみ）。
- ホスト権限 googleapis.com：Google ドライブ API へのアップロードのため。127.0.0.1：PC 内のローカル AI 連携サーバーとの通信のため（任意機能）。
- コンテンツスクリプト（全サイト）：設定したマウスボタンでダッシュボードに戻るためのキー監視のみ。ページ内容は読み取りません。
