# Chrome ウェブストア掲載文（日本語）

対象バージョン: 1.4.0（提出用）。

## 名前（45文字以内）
タブまとめん改

## 概要（132文字以内）※ダッシュボードでは編集できない。manifest の description（`_locales/ja/messages.json` の appDescription）から表示される。1.4.0 に入っている。
案件ごとにタブをまるごと保存・切り替え。ピン留め、一括操作、右クリック保存、Googleドライブのバックアップで、タブ地獄から抜け出す拡張機能。

## 詳細説明（ダッシュボードの「説明」欄にそのまま貼る）
タブが増えすぎて、どれが何の作業だったか分からない。明日の続きのために、タブを開きっぱなしにしている。
タブまとめん改は、そんな「タブ地獄」を終わらせる拡張機能です。

案件や作業ごとにタブを「スペース」として保存し、同じ Chrome ウィンドウの中で、タブ一式をワンクリックで切り替えます。今の案件のタブだけが開くので、頭の中もすっきりします。

■ こんな方におすすめ
・複数の案件を並行して進める Web 制作・開発・マーケティングの方
・調べもの、作業、連絡のタブが混ざりがちな方
・ブラウザを閉じるのが怖くて、タブを開いたままにしている方

■ 使い方
1. ツールバーのアイコンをクリックしてダッシュボードを開く
2. 「＋ スペース」で案件名を入力
3. 保存したいタブを開いた状態で「現在のタブを保存」をクリック
4. 左のスペース名をクリックすると、その案件のタブが一斉に開きます

■ 主な機能
【スペース】案件ごとにタブ一式を保存し、クリックひとつで切り替え。切り替えるときに今のタブを自動で保存することもできます。スペースごとに色とアイコンを付けられます。
【カテゴリー】スペースを3階層まで整理。ドラッグで並べ替え、色で見分けられます。お気に入りと最近使ったスペースからもすぐ開けます。
【タブグループ】Chrome のタブグループを、名前と色ごと保存・復元します。
【ピン留めタブ】Gmail やチャットなど常に使うタブはピン留めしておけば、スペースを切り替えても開いたまま。どのスペースにも保存されません。
【一括操作】タブを選んで、開く・別のスペースへ移動・グループへ入れる・アーカイブ・削除をまとめて実行。全選択と Shift での範囲選択に対応。
【元に戻す】削除やアーカイブの直後なら Ctrl/⌘+Z で取り消せます。
【右クリック保存】見ているページやリンクを、右クリックから好きなスペースに保存。ダッシュボードに戻る必要はありません。
【スペースの共有】選んだスペースだけをファイルや共有コードで書き出し、受け取った人は自分のデータに追加して使えます。案件の引き継ぎやチームへの共有に。URL の「?」以降を消して渡すこともできます。
【URL 一覧のコピー】Markdown、タイトル＋URL、URL のみの形式でクリップボードへ。報告やメモにそのまま使えます。
【検索とショートカット】タブのタイトルや URL で絞り込み。Ctrl/⌘+K でスペース検索、/ でタブの絞り込み、Ctrl/⌘+S で保存。マウスの「進む」ボタンでダッシュボードに戻れます。
【バックアップ】Google ドライブの専用フォルダに日時付きで保存。残す世代数を選べ、一覧から選んで復元できます（復元前のデータは退避し、取り消しも可能）。JSON の書き出し・読み込みと、定期的な自動バックアップ（毎時・6時間ごと・毎日）にも対応。
【使っていないスペースの自動整理】30〜365 日使っていないスペースを自動でアーカイブ、または削除（削除は 30 日間ゴミ箱に保持）。お気に入りと選択中のスペースは対象外です。
【見た目と言語】リスト表示とカード表示、ダークモード。日本語・英語・中国語（簡体・繁体）・韓国語・スペイン語・ポルトガル語・ドイツ語・フランス語・イタリア語の 10 言語に対応し、設定から切り替えられます。

■ データの扱い
保存したデータは、お使いの Chrome の中（chrome.storage.local）だけに保存されます。閲覧内容を外部へ送信する機能はありません。
Google ドライブへのバックアップは、あなたが「接続」して保存したときだけ、あなた自身のドライブに書き込みます（この拡張機能が作ったファイル以外にはアクセスしません）。

■ 有料版（Pro）について
ほとんどの機能は無料です。Pro 版（買い切り 300円・税込）では、Google ドライブへの自動バックアップが使えます。購入は設定画面の「Pro 版」から行えます。継続的な請求はありません。購入状況の確認のため、インストールごとのランダムな購入 ID だけを購入記録サーバーへ送ります（名前・メールアドレス・閲覧内容は送りません）。お支払いは Stripe（販売者として Link が表示されます）で行います。
利用規約・特定商取引法に基づく表記・プライバシーポリシー：設定画面の「Pro 版」からご覧いただけます。

## 権限の説明（ダッシュボード「プライバシーへの取り組み」用）
- tabs / tabGroups：開いているタブとタブグループを読み取り、スペースとして保存・復元するため。
- storage / unlimitedStorage：スペースと設定をローカルに保存するため。
- alarms：定期的な自動バックアップと、使っていないスペースの自動整理のため。
- downloads：JSON バックアップをダウンロードフォルダに書き出すため。
- contextMenus：右クリックメニュー「タブまとめん改に保存」のため。
- identity：Google ドライブへのバックアップ保存の認可を得るため（drive.file スコープのみ）。
- ホスト権限 googleapis.com：Google ドライブ API への保存・一覧・復元のため。127.0.0.1：PC 内のローカル AI 連携サーバーとの通信のため（任意機能）。
- コンテンツスクリプト（全サイト）：設定したマウスボタンでダッシュボードに戻る操作を検知するためだけに動作し、ページ内容は読み取りません。
