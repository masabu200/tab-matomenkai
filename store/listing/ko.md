# Chrome 웹 스토어 등록 정보 (한국어)

## 이름 (최대 45자)
Tab Matomen Kai – 탭 스페이스

## 요약 (최대 132자)
프로젝트마다 '스페이스'를 만들어 같은 창에서 탭 구성을 통째로 전환하세요. 저장, 복원, 일괄 작업, 실행 취소, 우클릭 저장을 지원하며 10개 언어로 제공됩니다.

## 상세 설명
Tab Matomen Kai는 프로젝트나 작업별로 탭을 '스페이스'로 저장하고, 같은 Chrome 창 안에서 탭 구성을 통째로 전환할 수 있게 해 주는 확장 프로그램입니다.

■ 주요 기능
- 스페이스: 프로젝트별로 탭 묶음을 저장하고 클릭 한 번으로 전환합니다. 전환할 때 현재 탭을 자동으로 저장할 수도 있습니다.
- 카테고리: 스페이스를 계층 구조로 정리합니다. 드래그로 이동하고, 색상과 아이콘으로 구분할 수 있습니다.
- 탭 그룹: Chrome 탭 그룹을 그대로 저장하고 복원합니다.
- 탭 일괄 작업: 탭을 선택해 열기, 이동, 그룹에 추가, 보관, 삭제를 할 수 있습니다. 전체 선택과 Shift 범위 선택을 지원합니다.
- 실행 취소: 삭제나 보관 직후에 되돌릴 수 있습니다(Ctrl/⌘+Z).
- URL 목록 복사: Markdown, 제목 + URL, URL만의 형식으로 클립보드에 바로 복사합니다.
- 우클릭 저장: 우클릭 메뉴에서 커서 아래의 페이지나 링크를 원하는 스페이스에 저장합니다.
- 키보드: Ctrl/⌘+S 저장, Ctrl/⌘+K 스페이스 검색, / 탭 필터링.
- 백업: JSON 내보내기/가져오기, 예약 자동 백업, Google 드라이브로의 수동 백업.
- 10개 언어: 영어, 일본어, 중국어 간체, 중국어 번체, 한국어, 스페인어, 포르투갈어(브라질), 독일어, 프랑스어, 이탈리아어. 설정에서 전환할 수 있습니다.

■ 데이터 처리
모든 데이터는 브라우저의 로컬 저장소에만 저장됩니다. Google 드라이브 백업은 사용자가 '연결'과 '지금 백업'을 누를 때만 사용자 본인의 드라이브에 기록됩니다. 탐색한 내용은 어디로도 전송되지 않습니다.

■ 유료판(Pro)
대부분의 기능은 무료입니다. Pro 버전(일회성 구매, 300엔)에서는 Google 드라이브 자동 백업을 사용할 수 있습니다. 설정 → Pro 버전에서 구매할 수 있으며, 정기 결제는 없습니다. 구매 상태 확인을 위해 설치마다 만들어지는 무작위 구매 ID만 구매 기록 서버로 보냅니다(이름·이메일·열람 내용은 보내지 않습니다). 결제는 Stripe가 처리하며 판매자로 Link가 표시됩니다.

## 권한 설명 (개발자 대시보드용)
- tabs / tabGroups: 열려 있는 탭과 탭 그룹을 읽어 스페이스로 저장하고 복원하기 위해 사용합니다.
- storage / unlimitedStorage: 스페이스와 설정을 로컬에 보관하기 위해 사용합니다.
- alarms: 예약된 자동 백업을 위해 사용합니다.
- downloads: JSON 백업을 다운로드 폴더에 기록하기 위해 사용합니다.
- contextMenus: 우클릭 메뉴 'Tab Matomen Kai에 저장'을 위해 사용합니다.
- identity: Google 드라이브에 백업을 저장하기 위한 권한을 얻기 위해 사용합니다(drive.file 범위만 사용).
- 호스트 권한 googleapis.com: Google Drive API에 업로드하기 위해 사용합니다. 127.0.0.1: 사용자 PC에 있는 선택 사항인 로컬 AI 연동 서버와 통신하기 위해 사용합니다.
- 콘텐츠 스크립트(모든 사이트): 대시보드로 돌아가기 위해 설정된 마우스 버튼만 감지합니다. 페이지 내용은 읽지 않습니다.
